Запуск функции: в папке проекта открыть терминал и ввести python main.py
Установка пакетов: в папке проекта открыть терминал и ввести pip install -r requirements.txt
Запуск тестов: в папке проекта открыть терминал и ввести python3.13 -m pytest test_main.py
